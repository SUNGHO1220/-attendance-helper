출결 업무 도우미

나이스에서 "월별 출결 현황" PDF 내려받는 방법

  1. 1 NEIS에 로그인한 뒤, 상단 메뉴에서 학급담임을 클릭합니다.

  2. 2 왼쪽 "학적" 항목에서 출결현황및통계를 클릭합니다.

  3. 3 화면 오른쪽 위 월별 출결현황 버튼을 클릭합니다.

  4. 4 새로 뜬 창에서 조회 기간을 확인한 뒤 조회를 누르고, 결과가 나오면 월별출력을 클릭합니다.

  5. 5 미리보기 화면 위쪽 저장 아이콘을 눌러 PDF를 선택하면 파일이 다운로드됩니다. 이렇게 받은 PDF를 왼쪽 "월별 출결 현황 업로드"에서 올려주세요.

기본 정보 설정

학년·반·담임 성함은 이 브라우저에만(localStorage) 저장됩니다.

월별 출결 현황 업로드

나이스에서 내려받은 "월별 출결 현황" PDF를 올리면, 아래에서 결석·지각·조퇴·결과 건수를 자동으로 분석해서 학생별로 서식을 만들어 줍니다.

확인(제출)일자·확인 방법·첨부서류는 결석 사유를 바탕으로 자동으로 채워 넣지만 추정일 뿐이니, 미리보기에서 검토하거나 직접 고쳐주세요. 보호자 성명처럼 PDF에 아예 없는 정보는 빈칸으로 남으니 인쇄 전에 손으로 채워주세요.

학생별 생성 문서

    미리보기

    왼쪽 학생 명단에서 문서를 선택하면 여기에 미리보기와 PDF가 표시됩니다.

    처음 저장할 때 저장할 폴더를 한 번 선택하면, 다음부터는 같은 폴더에 바로 저장됩니다. 다른 폴더로 바꾸려면 "저장 폴더 변경" 버튼을 눌러주세요.

    출결이 있었던 다음 등교일로 자동 계산했습니다(주말·공휴일이면 그 다음 평일). 다르면 달력에서 직접 골라 바꿔주세요.

    결석 사유를 바탕으로 확인 방법·첨부서류를 자동으로 추정해 넣어뒀습니다. 실제와 다르면 위에서 직접 골라 바꿔주세요 — 바꾸면 아래 미리보기에 바로 반영됩니다.

    담임의견서 (별도 문서)

    결석신고서의 첨부서류를 "담임의견서"로 고르거나, 지각·조퇴·결과 확인서에 출석인정 또는 질병으로 인한 지각·조퇴·결과 건이 있으면 결석신고서와는 별도의 PDF로 여기 자동 생성됩니다(여러건이면 날짜별로 각각). 위 문서를 저장한 뒤 이 문서(들)도 따로 저장해주세요.
